
# Табличные представления для просмотра файлов протоколов СУБД в формате CSV

## Проблема
1. Из файлов протоколов работы СУБД удобно отфильтровать нужные строки командами ОС 
   (`grep`, [`rg`](https://github.com/burntsushi/ripgrep)) через поиск подстрок.
   Более сложный анализ удобнее сделать на `SQL` через `SELECT` запросы.
   Пример: выборка нужных колонок, фильтрация, группировка и агрегация, сортировка.
1. Не все сотрудники могут самостоятельно посмотреть файлы с протоколами работы `PostgreSQL` за нужный день из-за ограничения `SSH` доступа на серверы СУБД.
1. Чтобы с промышленной среды забрать файлы протоколов для анализа, нужно согласование отдела ИБ и участие сисадминов.
1. В крупных компаниях настраивают отгрузку файлов протоколов в другую систему для возможности индексирования и быстрого поиска информации уже там.
   Это удобно, но для этого требуются дополнительные ресурсы по серверному оборудованию и сопровождению.
   К тому же отгрузка данных происходит не в реальном времени, а с задержками.

## Решение
1. Сделана возможность читать всегда актуальные данные из протоколов работы СУБД (файлов в формате `CSV`, а так же из архивов!) через табличные представления.
1. К табличным представлениям можно дать временный или постоянный доступ сотрудникам и/или 
   приложению с отдельной учётной записью в СУБД (без доступа к другим базам), что гораздо безопаснее `SSH` доступа к серверу.

## Настройка параметров сервера 

В конфигурационном файле СУБД нужно настроить сохранение протоколов в формате `CSV`:
```
log_destination = 'csvlog'
```
